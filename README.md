# HTML_website_for_techfest

A simple and interactive **HTML5-based Tech Fest website** created for **Sai University Tech Fest 2026**. The website presents event information, competitions, schedules, registration details, and an embedded YouTube video.

## 🌐 Project Overview

The **Sai University Tech Fest 2026** website is designed to provide participants with important information about the event in a simple and organized way.

The project demonstrates fundamental **HTML5 concepts**, including semantic elements, navigation links, lists, tables, forms, input fields, images, and embedded YouTube videos.

## ✨ Features

* 🏫 Tech Fest introduction
* 📋 Event highlights
* 🏆 Competition details
* 🕐 Detailed event schedule
* 📝 Participant registration form
* 👤 Personal information fields
* 🎯 Event selection
* 💻 Skills selection using checkboxes
* 👥 Individual/Team participation selection
* 📅 Preferred event date
* 🔗 Portfolio URL field
* 💬 Comments and additional information
* 🖼️ Event poster/image
* ▶️ Embedded YouTube event video
* 🔗 Navigation between different sections
* 📱 Basic responsive viewport configuration

## 🛠️ Technologies Used

## 🎥 YouTube Video

The website includes a YouTube video directly through an HTML `<iframe>`.

No video file is stored in the repository.

```html
<iframe
    width="600"
    height="350"
    src="https://www.youtube.com/embed/YOUR_VIDEO_ID"
    allowfullscreen>
</iframe>
```

Replace `YOUR_VIDEO_ID` with the ID of the YouTube video you want to display.

## 🚀 How to Run

### Option 1 — Open Locally

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.

### Option 2 — GitHub Pages

1. Upload the project to GitHub.
2. Go to **Settings → Pages**.
3. Select the appropriate branch.
4. Save the settings.
5. GitHub will generate a live website link.
